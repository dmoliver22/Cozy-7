# The Oxytocin Report (site)

Static site built with Astro 7. Plain-English evidence verdicts on oxytocin for 13 conditions, 8 guides, a trial tracker, a drug pipeline, a routing quiz, and dated updates. No oxytocin is sold; monetization routes to proven alternatives through disclosed `/go/` redirects.

- Read **LAUNCH.md** for deployment, placeholders, monetization rules, the lab-test plan and the 90-day content calendar.
- Read **content-brief/CONTENT_SPEC.md** before writing or editing any page.

```bash
npm install
npm run dev
npm run build && npm run lint:content && npm run check:links
```
